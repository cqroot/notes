# My KDE Plasma 6 Configuration

## Colors & Themes

Install dependencies:

```bash
yay -S plasma6-themes-layan-git
yay -S whitesur-kde-theme
pacman -S papirus-icon-theme
```

- Colors: `Breeze Dark`
- Application Style: `Breeze`
- Plasma Style: `Layan`
- Window Decorations: `WhiteSur-dark`
- Icons: `Papirus-Dark`
- Cursors: `Breeze Dark`
- Splash Screen: `Breeze`
- Login Screen (SDDM): `Breeze`
