# Linux 命令兼容性

## GNU Core Utilities

### `realpath`

`realpath` 是一个用于解析文件或目录绝对路径的命令行工具。如果目标文件是个符号链接，`realpath` 会返回其指向的实际路径。

其基本用法如下：

```bash
realpath <file>
```

该命令自 coreutils 8.15 版本新增（[realpath: a new program to print the resolved path](https://github.com/coreutils/coreutils/commit/77ea441f79aa115f79b47d9c1fc9c0004c5c7111)），在各个操作系统发行版的支持情况如下：

| 操作系统   | 包版本 | 是否支持 |
| :--------- | :----- | :------: |
| CentOS 6.x | 8.4    |    N     |
| CentOS 7.x | 8.22   |    Y     |

一个简单的替代方案是使用 `readlink`，它也是 coreutils 的一部分，从 4.5 版本开始支持（[New program, by Dmitry V. Levin.](https://github.com/coreutils/coreutils/commit/2ae02ab5b91daa8dc94ac42496a3ee701c25d1ac)）：

```bash
readlink -f <file>
```
