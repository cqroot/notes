# Disk Commands

- `fdisk`：传统工具，适用于 MBR 分区表（≤2TB 磁盘）。
- `gdisk`：现代工具，适用于 GPT 分区表（＞2TB 磁盘或 UEFI 系统）。
- `parted`：高级交互式工具，支持 MBR/GPT。

# fdisk / gdisk

```bash
fdisk -l  # 列出所有磁盘
```

# parted

## 查看块设备分区信息

```bash
parted -l
```

## 设置分区表类型

```bash
parted -s /dev/sdX mklabel gpt
```

其中，`gpt` 是 `LABEL-TYPE`，其值还可以为 `msdos`（mbr）。

## 新建分区

```bash
parted -s /dev/sdX mkpart PART-TYPE [FS-TYPE] START END
```

- `PART-TYPE` 是分区类型。
  - `primary`：主分区（MBR/GPT）；
  - `extended`：逻辑分区（仅 MBR）；
  - `logical`：扩展分区（仅 MBR）；
  - `<name>`：GPT 自定义分区名。
- `FS-TYPE` 是文件系统类型。mkpart并不会实际创建文件系统，FS-TYPE参数仅是让parted设置一个 1-byte 编码，让启动管理器可以提前知道分区中有什么格式的数据。
- `START` 是分区的起始位置。如果是第一个分区，建议使用 1MiB 或 1MB。
- `END` 是设备的结束位置。可以带单位，也可以用百分比。例如100%表示到设备的末尾。

示例：

```bash
parted -s /dev/sdX mkpart primary 1 100%
```

分区完成后执行以下命令查看分区：

```bash
parted -s /dev/sdX print
```

# 其他操作

```bash
wipefs -a /dev/sdX  # 清除所有分区签名
partprobe /dev/sdX  # 刷新分区表
mkfs.ext4 /dev/sdX1 # 格式化分区为 ext4
mkswap /dev/sdX2    # 格式化为 Swap 分区
swapon /dev/sdX2    # 激活 Swap
```

# MBR vs GPT

- MBR：兼容旧系统，最多 4 个主分区（或 3 主分区 + 1 扩展分区）。
- GPT：支持 > 2TB 磁盘，默认支持 128 个分区（可扩展），UEFI 系统必需。
