# 存储

## 单盘、JBOD、RAID

- 单盘
- JBOD（Just a Bunch Of Disks）无任何 RAID 功能，仅将多个物理磁盘合并为单一逻辑卷（串联模式），数据按顺序填充磁盘，无冗余或性能优化。
- RAID
  - 硬件 RAID 通过专有 RAID 控制器（插在 PCIe 插槽的独立硬件）管理磁盘阵列，所有 RAID 操作由控制器处理，独立于操作系统。
  - 软件 RAID 完全依赖主机 CPU 和操作系统实现 RAID 功能，无需专有硬件控制器。Linux 下一般使用 `mdadm` 实现。

## RAID 0 和 RAID 1

### RAID 0

- RAID 0 将数据分割成块，轮流写入所有磁盘，没有冗余。
- **读写性能**：RAID 0 由于数据分散在多个盘，因此其性能较好，读写带宽接近所有磁盘速度之和。
- **容量利用率**：RAID 0 的可用存储容量是所有磁盘容量之和，100% 存储利用率。
- **冗余能力**：RAID 0 没有任何冗余，任何一块磁盘故障，整个阵列数据全部丢失，可靠性低于单盘。

### RAID 1

- RAID 1 将数据同时写入两个（或更多）的磁盘中，写入数据为完全相同的副本。
- **读写性能**：RAID 1 需要将数据同时写入所有镜像盘，因此其写入速度略低于单盘。读取性能一般高于单盘，低于 RAID 1。
- **容量利用率**：RAID 1 的存储利用率低，无论多少块盘，实际获取的容量都是所有盘中最少容量。
- **冗余能力**：RAID 1 的优点是高冗余性。只要剩下一块完好的磁盘，数据都可以访问和恢复。
