# Scoop - Windows 软件包管理器

## 1. 安装

```bash
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
```

## 2. 常用命令

```bash
# 设置 PowerShell 代理
[net.webrequest]::defaultwebproxy = new-object net.webproxy "http://127.0.0.1:7890"
```

| 命令                  | 功能               |
| :-------------------- | :----------------- |
| `scoop install <app>` | 安装 <app>         |
| `scoop update <app>`  | 更新 <app>         |
| `scoop update`        | 更新 scoop         |
| `scoop update *`      | 更新所有 app       |
| `scoop status`        | 查看需要更新的 app |
| `scoop cache rm *`    | 清除所有缓存       |
