# Linux iptables

## Netfilter

Netfilter 是 Linux 内核内置的网络包过滤和处理框架。

### 表（Table）

表是用于特定功能的规则集合。

1. `raw` 表： 用于配置数据包是否绕过连接跟踪（Connection Tracking）。
2. `mangle` 表： 用于特殊的数据包修改（如修改 TOS 位、设置 MARK 标记）。
3. `nat` 表： 负责网络地址转换（SNAT, DNAT）。
4. `filter` 表： 最常用的表，负责包过滤（允许/阻止）。

### 链（Chain）

链存在于表中，是规则的有序列表。数据包在流经网络栈时会经过特定的链，链中的规则会按顺序被检查。内置链有 5 个：

1. `PREROUTING`： 数据包刚进入网卡、路由决策之前。
2. `INPUT`： 数据包目标是本机（路由决策后确定）。
3. `FORWARD`： 数据包需要被转发到其他机器（本机充当路由器）。
4. `OUTPUT`： 数据包由本机进程产生，准备发送出去。
5. `POSTROUTING`： 数据包即将离开网卡、路由决策之后。

### 规则（Rule）

规则是链中的具体条目。每条规则包含匹配条件（match criteria）和目标动作（target）。

### 目标（Target）

目标是当数据包匹配一条规则时，决定对其执行的动作。常见目标：

- `ACCEPT`： 允许数据包通过。
- `DROP`： 直接丢弃数据包（不发送任何响应）。
- `REJECT`： 丢弃数据包，并发送错误响应（如 TCP RST 或 ICMP port unreachable）。
- `LOG`： 将匹配的数据包信息记录到系统日志（如 `/var/log/syslog` 或 `/var/log/messages`）。
- `SNAT`： 在 nat 表的 POSTROUTING 链中执行源地址转换。
- `DNAT`： 在 nat 表的 PREROUTING 链中执行目标地址转换。
- `MASQUERADE`： SNAT 的一种特殊形式，用于动态获取 IP（如拨号上网）的场景。
- `RETURN`： 停止在当前链中继续匹配，返回到调用该链的上一条规则（或默认策略）继续执行。
- `REDIRECT`： 将数据包重定向到本机的另一个端口（常用于透明代理）。

## iptables

iptables 是用户空间工具，用于配置 Netfilter 框架中定义的规则和策略。它本身不是防火墙，而是防火墙规则的配置器。
